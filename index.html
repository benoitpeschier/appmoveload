Mode d'emploi

Inviter un athlète

Dans MoveLoad, l'athlète ouvre Réglages > Synchronisation > Scanner un QR code et vise cette image. Les trois réglages sont remplis d'un coup.

Ce code contient le code d'équipe, qui est la seule protection des données de l'équipe. Ne le publiez pas et ne le laissez pas affiché sur un écran sans surveillance.
